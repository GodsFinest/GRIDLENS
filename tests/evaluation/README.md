# Evaluation fixtures

`dev_cases.json` and `heldout_cases.json` are the legacy latent-parameter test
set. They are retained for historical reproducibility but are superseded as
current physical evidence by
[`services/evaluation/physical_cases.py`](../../services/evaluation/physical_cases.py).
See [`docs/evaluation.md`](../../docs/evaluation.md) for the active evaluation
contract.
