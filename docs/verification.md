# Verification boundaries

## Supported verification, without word-overlap shortcuts

The ledger is generated by tools. FACT verification accepts exact quotations,
unit conversions with an otherwise identical full statement, and a finite set
of fully matched templates with bound subjects/measurement roles. Unknown prose
fails closed. This is not general natural-language entailment or certification
of a source's truth. Documentation claims quote an actual retrieved sentence;
exact source identifiers replace substring matching.

INFERENCE verification reruns an allowlisted function over exactly its cited,
verified premises and compares both the typed result and canonical rendering.
Measured overcurrent is tied to the actual phase, primary RMS, and configured
pickup threshold. It does not prove which relay element caused a trip. An
incomplete record supports an insufficiency conclusion, not a fabricated duration.
Unknown rules, mutated conclusions and caller-supplied verification statuses fail.
H3 remains a separate rule-based conflict-resolution trace; it is not emitted as
an unexecuted causal inference. H2 remains a hypothesis, not a proven misoperation.

LLM narrative output must consist of complete verified quotations and allowed
section labels. Added causal, negative, temporal or subject-swapped wording falls
back to the deterministic report. Entity/quantity checks supply diagnostics only;
they cannot establish narrative faithfulness. Recommendations are allowlisted
review guidance, not device-specific instructions to de-energize/reclose equipment.

## Physical input boundary

Supported COMTRADE subset: explicit 1999/2013 revision, ASCII, a single positive
fixed sampling rate, zero channel skew, uniquely named channels, explicit positive
transformer ratios, and A/kA/V/kV primary or secondary values. Parsing applies
affine calibration, SI-unit conversion and secondary-to-primary ratio **before**
thresholding. Original unit/scaling/ratio provenance travels with measurements.
Unsupported metadata, non-finite samples, malformed rows, invalid digital values,
noncontiguous indices and inconsistent timestamps are rejected. A record missing
even one declared sample is incomplete. The legacy Incident C also has 0:0 CT
metadata and is now rejected as invalid rather than interpreted as primary current.

RMS uses complete nominal cycles when available, and pickup uses RMS—not a
sinusoidal peak approximation on an arbitrary waveform. 52a falling and 52b rising
contact edges are recognized. Without a detected onset/pickup, recording start is
not invented as fault inception. Contact opening is not proof of electrical fault
clearance. Onset detection assumes an initial stable prefault interval; a fault
already present at recording start can require abstention/engineering review.
The live physics path is RMS-magnitude triage, not waveform phasor estimation.

## Evaluation hierarchy

1. Keep the 26 curated regressions; these share a small seeded topology/incidents.
2. Generate 80 development sine-wave and 40 held-out harmonic-family recordings.
   Actual CFG/DAT files pass through the normal WaveformTool and LangGraph workflow.
3. Compare measurements against generator amplitudes, known digital edges, phase,
   pickup and truncation labels outside the workflow. RMS tolerance is 1%; onset
   tolerance one nominal cycle; digital-edge tolerance one sample. Report the
   measured RMS in a verified report claim and retain raw input hashes.
4. Mutate amplitudes/labels and verify the independent oracle catches the change.
   Development and held-out waveform families and DAT hashes must be disjoint.

This is synthetic signal-family coverage. It is **not** held-out topology coverage,
real utility telemetry, field root-cause accuracy or a competing live-LLM benchmark.
The analytical formula fixtures remain historical; they no longer masquerade as
120 distinct physical investigations over five reused recordings.

## Live provider discipline

Offline tests inject MockLLMProvider and make no provider calls. Live comparison
requires explicit `allow_live=True` and configured credentials. Without it, the
result is `not_run`, with null rates. A failing live provider raises, records a
fallback/violation, and never silently turns into the mock. “Faithful” here means
accepted under the constrained quotation contract, not unrestricted factual prose.

## Reproduce

```sh
python -m pytest --cov=domain --cov=services --cov-fail-under=80 -q
python -m services.evaluation.physical_cases --split dev
python -m services.evaluation.physical_cases --split heldout
python scripts/verify_seed.py
```

Run with `LLM_PROVIDER=mock MODEL_PROVIDER=mock` for offline CI. The source corpus,
topology and simulator fixtures are not authenticated field observations. API-key
authentication/RBAC are demonstration controls; do not connect to live OT systems.
